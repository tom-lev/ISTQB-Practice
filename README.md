# ✦ תרגול ISTQB — ISTQB CTFL Practice App

אפליקציית ווב חד-עמודית (SPA) לתרגול לקראת בחינת **ISTQB Foundation Level (CTFL)** בעברית — כוללת חידונים, סימולציית בחינה מלאה, כרטיסיות מושגים, משחקי התאמה, מעקב סטטיסטיקות וסנכרון בענן.

🔗 **דמו חי:** https://tom-lev.github.io/ISTQB-Practice/

---

## ✨ תכונות עיקריות

### 🎲 מצבי חידון
- **חידון אקראי** — בחירת כמות שאלות, מקור וסינון לפי רמת קושי (K1/K2/K3).
- **סימולציית בחינה** — 40 שאלות, טיימר של 60 דקות, חלוקה מדויקת לפי תקן ISTQB הרשמי (K1/K2/K3), סף מעבר 65%.
- **מצב בזק** — טיימר של 10–90 שניות לכל שאלה; אי-מענה בזמן נספר כטעות.
- **מצב רצף** — טעות אחת מסיימת את הריצה; מעקב אחר שיא אישי.
- תרגול ממוקד לפי **שגיאות קודמות** או **שאלות מסומנות בכוכב**.

### 📚 תרגול מושגים
- **כרטיסיות (Flashcards)** — 324 מושגי מפתח, עם תצוגת רשת או כרטיס-אחר-כרטיס, כיוון תצוגה (מושג↔הגדרה), חיפוש, ערבוב וסימון "ידוע".
- **משחק התאמות** — התאמת מושגים להגדרות שלהם מול הזמן.
- **בחן את עצמך** — חידון מבוסס מונחון (glossary) עם ניקוד.

### 🛠️ פיצ'רים בזמן חידון
- סימון שאלות בכוכב לחזרה מאוחרת.
- הוספת הערה אישית לכל שאלה.
- קישורים ישירים לקובצי המקור והתשובות הרשמיים של ISTQB.
- סקירת תשובות מלאה בסיום כל חידון.
- דיווח על בעיה בשאלה ישירות מהאפליקציה.

### 📊 סטטיסטיקות וענן
- מעקב אחר שיא אישי, אחוזי דיוק, כיסוי בנק השאלות והיסטוריית חידונים.
- **התחברות עם Google** לשמירת התקדמות (שגיאות, כוכבים, הערות, שיאים והיסטוריה) וסנכרון בין מכשירים.
- ניתן לשחק גם כאורח, ללא שמירה.

### 🌗 נוסף
- תמיכה במצב כהה/בהיר.
- אפקטי סאונד הניתנים להפעלה/כיבוי.
- ממשק דו-לשוני (עברית/אנגלית) בחלק מהמסכים.

## 🗂️ מבנה הפרויקט

```
ISTQB-Practice/
├── index.html          # מבנה האפליקציה כולה (SPA) — כל המסכים
├── app.js              # לוגיקת האפליקציה: חידונים, כרטיסיות, משחקים, סטטיסטיקות
├── firebase.js         # אתחול Firebase, התחברות Google וסנכרון נתונים בענן
├── styles.css          # עיצוב האפליקציה (כולל מצב כהה/בהיר)
├── questions.json       # בנק שאלות (אנגלית)
├── questions_he.json    # בנק שאלות (עברית) — בחינות לדוגמה גרסאות א'-ד' ומילות מפתח
├── glossary_he.json     # מונחון (324 מושגים) לכרטיסיות ולמשחקי ההתאמה
└── admin.html           # מסך ניהול/עריכה של תוכן השאלות
```

## 🧱 טכנולוגיות

- **HTML / CSS / JavaScript** — ללא framework, אפליקציה סטטית טהורה (Vanilla JS).
- **Firebase** — Authentication (Google Sign-In) ו-Firestore לשמירת התקדמות המשתמש בענן.
- **GitHub Pages** — אירוח הדמו החי.
- גופנים: Google Fonts — `Space Mono`, `Syne`, `Inter`.

## 📖 אודות ISTQB CTFL

ISTQB (International Software Testing Qualifications Board) היא הסמכה בינלאומית לבודקי תוכנה. רמת ה-Foundation Level (CTFL) היא רמת הכניסה, ומוכיחה ידע בסיסי בתורת בדיקות התוכנה. האפליקציה נבנתה כדי לסייע בהכנה לבחינה זו בעברית, ומכילה שאלות מ-5 מקורות: בחינות לדוגמה גרסאות א'–ד' וחידון מילות מפתח.
